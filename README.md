# 🤖 AI-Assisted MVP Experiments

I'm also exploring **AI-assisted software development and vibe coding** as part of my learning process.

The projects in this section were created through iterative collaboration with **ChatGPT**, with the application code generated with AI assistance.

My role focused on:

- identifying a real problem or use case
- defining the application requirements
- designing features and application behaviour
- testing generated implementations
- identifying bugs and usability problems
- providing feedback and iterating on solutions
- deploying and using the final application

I consider these projects **MVP experiments rather than demonstrations of traditional coding ability**.

The purpose is to understand how AI can be used as a development tool while also learning about application architecture, debugging, product thinking and the limitations of AI-generated software.
